# UWB 채널과 다중 경로

!!! spec "규격 · 개정판"
    IEEE 802.15.4a 채널 모델 최종 보고서 (IEEE 802.15-04-0662, CM1–CM9) · Saleh-Valenzuela 클러스터 모델

!!! basic "한눈에 보기"
    실내에서 전파는 벽, 바닥, 천장, 가구에 부딪혀 여러 길로 도착합니다. 협대역 무선에서는 이 반사파들이 **겹쳐서** 신호가 갑자기 약해지는 **페이딩**이 생깁니다.

    UWB는 시간 분해능이 약 2 ns라서 반사파들이 **따로따로** 보입니다. 수신기는 경로마다 언제, 얼마나 세게 왔는지를 그대로 볼 수 있는데, 이것을 **채널 임펄스 응답(CIR)**이라고 합니다.

    측거에 필요한 것은 CIR의 **첫 경로**입니다. 가장 센 경로가 아니라 **가장 먼저 온 경로**가 직선 거리에 해당합니다.

## CIR 읽기 { .l2 }

| 용어 | 뜻 | 측거에서의 의미 |
|---|---|---|
| 첫 경로 (first path) | 처음으로 잡음 위로 올라온 경로 | 거리 계산의 기준 |
| 최강 경로 (peak path) | 가장 에너지가 큰 경로 | LoS에서는 보통 첫 경로와 같음 |
| 지연 확산 (delay spread) | 경로들이 퍼진 시간 폭 (RMS) | 실내 수–수십 ns |
| 클러스터 | 비슷한 시각에 몰려 오는 경로 묶음 | 큰 반사체(벽 등)마다 하나씩 생김 |

LoS에서는 첫 경로가 가장 세서 문제가 적지만, 사람 몸이나 벽이 직선 경로를 가리면 첫 경로가 약해지고 뒤의 반사파가 더 세집니다. 이때 수신기가 첫 경로를 놓치면 거리가 길게 나옵니다([전파 지연과 LoS/NLoS](los-nlos.md)).

## 802.15.4a 채널 모델 { .l2 }

802.15.4a 작업 그룹은 UWB 성능 평가용 표준 채널 모델을 만들었습니다. 환경별로 파라미터가 다릅니다.

| 모델 | 환경 | 특징 |
|---|---|---|
| CM1 / CM2 | 주거 LoS / NLoS | 가정집, 지연 확산 중간 |
| CM3 / CM4 | 사무실 LoS / NLoS | 칸막이·벽 많음 |
| CM5 / CM6 | 실외 LoS / NLoS | 교외 환경 |
| CM7 / CM8 | 산업 LoS / NLoS | 금속 반사체 많음, 지연 확산 김 |
| CM9 | 개활지 실외 | 농장 등 |

각 모델은 **경로 손실 지수**, 클러스터 도착률, 클러스터·경로 감쇠 상수, 페이딩 분포 등을 정합니다. 칩 제조사와 연구자가 수신기 알고리즘을 비교할 때 공통 기준으로 씁니다.

## 협대역 페이딩과의 차이 { .l2 }

| 항목 | 협대역 (예: 20 MHz) | UWB (499.2 MHz) |
|---|---|---|
| 한 분해 구간에 섞이는 경로 수 | 많음 → 레일리 페이딩 | 적음 → 페이딩 깊이 작음 |
| 위치를 조금 옮기면 | 수신 세기가 수십 dB 출렁임 | 전체 에너지는 비교적 안정 |
| 다중 경로의 활용 | 등화·MIMO로 처리 | 경로별 에너지를 모으는 수신(RAKE) 가능, 측거는 첫 경로만 사용 |

??? expert "전문가 노트 — Saleh-Valenzuela 모델과 소규모 페이딩"
    802.15.4a 모델은 **Saleh-Valenzuela(S-V)** 구조를 따릅니다. 클러스터 도착은 도착률 \(\Lambda\)의 포아송 과정, 클러스터 안의 경로 도착은 두 가지 도착률을 섞은 포아송 혼합으로 모델링하고, 평균 전력은 클러스터 감쇠 \(\Gamma\)와 경로 감쇠 \(\gamma\)의 이중 지수로 줄어듭니다.

    \[
    h(t) = \sum_{l}\sum_{k} a_{k,l}\, \delta(t - T_l - \tau_{k,l}), \qquad
    E\{|a_{k,l}|^2\} \propto e^{-T_l/\Gamma}\, e^{-\tau_{k,l}/\gamma}
    \]

    소규모 진폭 분포는 레일리가 아니라 **나카가미(Nakagami-m)** 분포를 쓰는데, 분해 구간당 경로 수가 적어 m 값이 1보다 큰(페이딩이 덜한) 경우가 많기 때문입니다. 일부 NLoS 모델(CM2·CM4 등)에는 첫 클러스터 안에서 전력이 처음에 **증가했다가** 감소하는 형태가 들어가 있는데, 이는 첫 경로가 최강 경로가 아닌 상황을 모델에 반영한 것입니다.

    또 802.15.4a 모델은 경로 손실의 **주파수 의존성**(\(PL(f) \propto f^{-2\kappa}\))을 넣어, 대역이 넓어 채널 안의 저주파와 고주파가 다르게 감쇠하는 UWB 특성을 반영합니다.
