# 링크 버짓

!!! spec "규격 · 개정판"
    FCC 47 CFR 15.517·15.519 (평균 −41.3 dBm/MHz, 1 ms 평균; 피크 50 MHz당 0 dBm) · ETSI EN 302 065 · Friis 자유 공간 식 · 계산: `tools/uwb_numbers.py`

!!! basic "한눈에 보기"
    링크 버짓은 "보낸 전력에서 잃는 것을 빼고, 받는 쪽이 알아들을 수 있는 최소 전력까지 얼마나 여유가 있나"를 따지는 계산입니다.

    UWB는 송신 전력이 아주 작습니다. 500 MHz 채널 전체를 한도까지 채워도 **약 −14.3 dBm**(Wi-Fi 휴대폰의 수천분의 1)입니다. 그런데도 수십 m를 가는 이유는 수신기가 **수많은 펄스를 모아(상관)** 잡음 아래의 신호를 끌어올리기 때문입니다.

    결국 UWB의 도달 거리는 "얼마나 세게 쏘나"가 아니라 **"얼마나 오래 모으나"**(프리앰블 길이, 데이터율)로 조절합니다.

## 링크 버짓 식 { .l2 }

\[
P_{rx} = \text{EIRP} + G_{rx} - L_{path} - L_{body/wall}, \qquad
\text{여유} = P_{rx} - S_{rx}
\]

| 항목 | 값 (예) | 메모 |
|---|---|---|
| EIRP | −14.3 dBm | −41.3 dBm/MHz × 499.2 MHz |
| 수신 안테나 이득 \(G_{rx}\) | 0 dBi | 휴대폰은 0 dBi 이하인 경우가 많음 |
| 자유 공간 손실 1 m (Ch9) | 50.5 dB | 주파수가 높을수록 큼 |
| 자유 공간 손실 10 m (Ch5 / Ch9) | 68.7 / 70.5 dB | 거리 10배 → 20 dB |
| 열잡음 (499.2 MHz) | −87.0 dBm | −174 dBm/Hz + 10·log₁₀(499.2 MHz) |
| 수신 잡음 지수 | 수 dB | 칩·프런트엔드에 따라 다름 |
| 몸·벽 손실 | 수–수십 dB | NLoS에서 가장 큰 변수 |

10 m 떨어진 Ch9에서 수신 전력은 약 −84.8 dBm로, 잡음 지수 6 dB를 더한 잡음 전력(약 −81 dBm)보다 낮습니다. 펄스 하나로는 SNR이 음수지만, 프리앰블과 데이터 심볼에서 수백–수천 개 펄스를 모으므로 동기와 복조가 됩니다.

## 감도와 도달 거리 { .l2 }

수신 감도 \(S_{rx}\)는 데이터율, 프리앰블 길이, 수신기 구현에 따라 크게 다릅니다. 자유 공간(LoS, 0 dBi 안테나, 기타 손실 없음)에서 감도에 따른 이론 거리는 다음과 같습니다.

| 수신 감도 | Ch5 (6.5 GHz) | Ch9 (8.0 GHz) |
|---|---|---|
| −90 dBm | 약 22 m | 약 18 m |
| −95 dBm | 약 40 m | 약 32 m |
| −100 dBm | 약 71 m | 약 57 m |
| −105 dBm | 약 126 m | 약 102 m |

실제 환경에서는 안테나 손실, 몸·벽 손실, 다중 경로 때문에 이보다 짧습니다. 그래도 표에서 두 가지 경향은 그대로입니다.

- **Ch9는 Ch5보다 약 1.8 dB 불리**합니다(주파수 비 7987.2/6489.6). 대신 Ch9는 여러 나라에서 공통으로 쓸 수 있어 많이 쓰입니다([주파수 규제](regulation.md)).
- **감도 5 dB 개선 = 거리 약 1.8배**. 프리앰블을 길게 하거나 데이터율을 낮추면 감도가 좋아집니다.

## 거리를 늘리는 방법 { .l2 }

| 방법 | 효과 | 대가 |
|---|---|---|
| 프리앰블 길게 | 동기·첫 경로 검출 감도 ↑ | 공중 시간·전력 ↑ |
| 데이터율 낮게 | 데이터 복조 감도 ↑ | 페이로드 시간 ↑ |
| 안테나 이득·배치 개선 | 수 dB | 기구 설계 제약 |
| 송신 듀티 사이클 활용 | 1 ms 평균 규정 안에서 순간 전력 ↑ | 피크 한도, 규제 해석 |
| 802.15.4ab MMS | 측거 신호를 여러 조각으로 나눠 에너지 모음 | 새 표준·칩 필요 ([MMS 측거](../next/mms-ranging.md)) |

??? expert "전문가 노트 — 1 ms 평균과 피크 한도"
    FCC의 −41.3 dBm/MHz는 **1 MHz 분해능 대역폭, 1 ms 평균**으로 측정합니다. 측거 프레임은 보통 수백 µs 이하이고 측거 주기는 수십–수백 ms이므로, 1 ms 창 안에 프레임 하나만 들어가도록 송신하면 **프레임 동안의 순간 PSD를 평균 한도보다 높일 수** 있습니다. 예를 들어 1 ms 중 250 µs만 송신하면 이론상 약 6 dB를 더 쓸 수 있습니다.

    다만 **피크 한도**(50 MHz 대역폭에서 0 dBm EIRP, 측정 대역폭에 따라 환산)와 칩의 최대 출력, 다른 나라 규제의 측정 방식 차이 때문에 무한정 올릴 수는 없습니다. 칩 제조사의 "송신 전력 부스트" 설정이 바로 이 원리이며, 인증 시험 조건과 함께 검토해야 합니다.

    또 하나의 함정은 **안테나 효율**입니다. 휴대폰 UWB 안테나는 금속 프레임과 손 때문에 효율이 낮고 방향에 따라 수 dB–10 dB 이상 출렁입니다. 링크 버짓에서 "0 dBi" 가정은 낙관적인 출발점일 뿐입니다.
