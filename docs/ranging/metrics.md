# 성능 지표

!!! spec "규격 · 개정판"
    IEEE 802.15.4z-2020 (측거 보고, 측거 품질 정보) · FiRa 인증 프로그램 (적합성·상호운용 시험, 세부 기준은 회원 문서) · CCC Digital Key Release 3 (측거 요구 사항, 회원 문서) · ISO/IEC 18305 (실내 측위 시스템 시험·평가) · 계산: `tools/uwb_numbers.py`

!!! basic "한눈에 보기"
    "UWB 정확도 10 cm"라는 말만으로는 거의 아무것도 알 수 없습니다. **평균이 10 cm 틀린다**는 것인지, **10번 중 9번이 10 cm 안**이라는 것인지, LoS에서인지 주머니 속에서인지에 따라 전혀 다른 성능이기 때문입니다.

    활쏘기에 비유하면, 화살이 과녁 중심에서 한쪽으로 몰려 있으면 **정확도(편향)**가 나쁜 것이고, 넓게 흩어져 있으면 **정밀도(산포)**가 나쁜 것입니다. 둘 다 봐야 하고, 가끔 과녁 밖으로 나가는 화살(**이상치**)이 얼마나 되는지도 봐야 합니다.

    여기에 "얼마나 자주, 얼마나 빨리, 얼마나 적은 전력으로, 몇 개의 기기와 동시에" 잴 수 있는지가 더해져야 실제 서비스 성능이 됩니다.

## 정확도 지표 { .l2 }

| 지표 | 정의 | 무엇을 보여 주나 |
|---|---|---|
| 편향 (평균 오차) | \(\overline{\hat d - d}\) | 보정 상태 (안테나 지연 등) |
| 표준편차 | 오차의 산포 | SNR·다중 경로에 따른 흔들림 |
| RMSE | \(\sqrt{\text{편향}^2 + \sigma^2}\) | 둘을 합친 한 숫자 |
| 백분위 (CDF 90·95%) | 오차 절댓값의 90·95% 지점 | 이상치·NLoS 꼬리 |
| CEP / R95 (위치) | 위치 오차 원의 반지름 50%·95% | 2D 위치 성능 |
| 각도 오차 | AoA 오차의 평균·백분위, 각도 범위별 | FoV 안팎 성능 |

거리 오차가 정규분포에 가깝다면 평균·표준편차로 충분하지만, UWB 오차는 NLoS 때문에 **한쪽(양수)으로 긴 꼬리**를 가집니다. 그래서 실무 보고서는 CDF 곡선과 90·95% 백분위를 함께 적고, LoS와 NLoS(몸 가림, 벽 뒤, 주머니 속)를 나눠 보고하는 것이 좋습니다.

## 시스템 지표 { .l2 }

| 지표 | 정의 | 영향을 주는 것 |
|---|---|---|
| 측거 성공률 | 시도한 측거 중 유효 결과 비율 | 링크 버짓, 간섭, 충돌, 가림 |
| 갱신율 | 초당 측거·위치 결과 수 | 측거 블록 간격, 참여 기기 수 ([측거 라운드 구조](../mac/ranging-rounds.md)) |
| 지연 | 측정 시점 → 앱이 결과를 받는 시점 | 지연 모드, 호스트 처리, 필터 |
| 동작 거리 | 성공률이 기준 이상인 최대 거리 | 채널, 프리앰블 길이, 안테나 ([링크 버짓](../basics/link-budget.md)) |
| 전력 | 측거 1회당 에너지, 평균 소비 전류 | 메시지 수, 수신 대기 시간 ([저전력 동작](../mac/low-power.md)) |
| 용량 | 동시에 지원하는 태그·응답자 수 | 방식 (TWR vs TDoA), 슬롯 구조 |
| 보안 성능 | 거리 단축 공격에 대한 내성 | STS 구성, 첫 경로 검증 ([보안](../security/index.md)) |

이 지표들은 서로 맞바꿈 관계입니다. 프리앰블을 길게 하면 동작 거리와 성공률은 오르지만 공중 시간과 전력이 늘고, 갱신율을 올리면 배터리 수명이 줄어듭니다. 서비스 요구(디지털 키의 문 앞 판단, 물류 태그의 수년 배터리, 내비게이션의 갱신율)에 맞춰 조합을 고릅니다.

??? expert "전문가 노트 — CEP 환산, 시험 설계, 보고 시 주의"
    **원형 정규분포의 CEP.** 위치 오차가 x·y 각각 표준편차 \(\sigma\)인 독립 정규분포면 오차 반지름은 레일리 분포를 따릅니다.

    \[
    \text{CEP}_{50} = \sigma\sqrt{2\ln 2} \approx 1.18\,\sigma, \qquad
    R_{95} = \sigma\sqrt{-2\ln 0.05} \approx 2.45\,\sigma
    \]

    GDOP 1.0인 정사각형 중앙(축마다 \(\sigma_r/\sqrt2\))에서 측거 표준편차가 10 cm라면 CEP50 ≈ 8.3 cm, R95 ≈ 17 cm입니다. 실제 분포는 NLoS 꼬리 때문에 R95가 이 값보다 훨씬 클 수 있으므로, 이 환산은 LoS 기준선으로만 씁니다.

    **시험 설계.** (1) 기준 거리·위치는 레이저 거리계나 모션 캡처처럼 측정 대상보다 한 자릿수 이상 정확한 장비로 잽니다. (2) 기기 방향(정면·측면·뒷면)과 사람 손·주머니 같은 실사용 자세를 조건으로 둡니다. (3) AoA는 회전대에서 각도별로 재고 FoV 안과 밖을 나눠 적습니다. (4) 측거 성공률은 실패를 빼고 정확도를 계산하므로 반드시 함께 적습니다. ISO/IEC 18305는 실내 측위 시스템 평가 시나리오와 지표의 공통 틀을 제공합니다.

    **보고 시 주의.** "정확도 ±10 cm"처럼 범위만 적힌 수치는 몇 % 백분위인지, 편향 보정 후인지, 필터 적용 후인지 확인해야 합니다. 필터 후 값은 정적 시험에서는 좋아 보이지만, 움직일 때는 위치가 실제보다 뒤처지는 지연 오차로 나타납니다. 다른 기술과의 비교는 [UWB vs BLE CS vs Wi-Fi RTT vs 5G](../reference/positioning-comparison.md)를 참고하세요.
