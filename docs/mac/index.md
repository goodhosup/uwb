# MAC

이 섹션은 IEEE 802.15.4 MAC 계층이 UWB 측거를 어떻게 담아내는지 다룹니다. PHY가 "펄스를 언제 정확히 보내고 받았나"를 책임진다면, MAC은 **누가, 언제, 어떤 프레임으로** 측거 메시지를 주고받을지를 정합니다. 802.15.4z는 이 MAC에 측거 전용 IE와 블록·라운드·슬롯 구조를 더했고, FiRa·CCC는 그 위에서 실제 세션 동작을 고정합니다.

!!! basic "Wi-Fi·BLE MAC과 다른 점 미리 보기"
    1. **데이터보다 시각** — 프레임의 목적이 데이터 전달보다 "정확한 송수신 시각을 남기는 것"입니다. 그래서 응답 지연이 정해진 값이어야 하고, 타임스탬프는 나중 프레임에 실어 보냅니다.
    2. **경합보다 일정** — 대부분의 측거는 컨트롤러가 정한 시간 슬롯 안에서 진행됩니다. 반송파 감지는 거의 쓰이지 않습니다.
    3. **연결 설정은 밖에서** — 세션 키와 파라미터는 BLE 같은 대역 외(OOB) 채널로 미리 맞추고, UWB MAC은 측거 라운드만 돌립니다.
