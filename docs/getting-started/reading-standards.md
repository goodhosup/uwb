# 표준 문서 읽는 법

!!! spec "규격 · 개정판"
    IEEE Std 802.15.4-2020 (통합본) · IEEE Std 802.15.4z-2020 (Amendment: Enhanced UWB PHYs and Associated Ranging Techniques) · IEEE 802.15.4ab (작업 중) · IEEE GET Program (무료 열람)

!!! basic "한눈에 보기"
    IEEE 802.15.4 표준은 Wi-Fi(802.11)와 같은 방식으로 관리됩니다. **통합본(revision) 하나 + 그 뒤의 개정판(amendment)들**입니다.

    - **통합본**: 그때까지의 개정판을 합친 전체 문서. 예: 802.15.4-2011, 802.15.4-2015, 802.15.4-2020
    - **개정판**: 통합본을 "이렇게 고쳐라"라고 적은 변경 문서. 예: 802.15.4z-2020

    UWB를 공부하려면 **802.15.4-2020 통합본 + 802.15.4z-2020 개정판**을 함께 봐야 합니다. 802.15.4는 Zigbee·Thread가 쓰는 O-QPSK PHY, Wi-SUN의 SUN PHY 등 UWB와 무관한 내용이 대부분이라, 필요한 절만 골라 읽는 법을 아는 것이 중요합니다.

## 802.15.4 통합본에서 UWB 관련 부분 { .l2 }

802.15.4는 여러 PHY가 하나의 MAC을 공유하는 구조입니다. UWB 독자가 볼 곳은 다음과 같습니다.

| 영역 | 내용 | 이 핸드북 위치 |
|---|---|---|
| 앞부분 (정의·약어) | 용어 정의, 약어 | [약어 사전](../reference/glossary.md) |
| MAC 기능 설명 | PAN, 채널 접근, **측거(ranging)** 기능 설명 | [MAC](../mac/index.md), [측거와 측위](../ranging/index.md) |
| MAC 프레임 형식 | 프레임 구조, **Header/Payload IE** (측거 IE 포함) | [MAC 프레임과 IE](../mac/frame-ie.md) |
| MAC 서비스 | MCPS/MLME 프리미티브 (측거 요청·보고 등) | |
| PHY 공통 요구사항 | **채널 할당**, 타이밍 요구사항 | [채널 번호와 대역](../phy/channels.md) |
| **HRP UWB PHY 절** | 프레임(SHR·PHR·STS·페이로드), 프리앰블 코드, 변조·부호화, 펄스 | [HRP 프레임 구조](../phy/hrp-frame.md) |
| **LRP UWB PHY 절** | 저 PRF UWB | [LRP PHY](../phy/lrp.md) |
| 부록 | 측거 관련 정보성 부록, 시험 벡터, PICS | |

802.15.4z는 이 중 HRP UWB PHY 절과 LRP UWB PHY 절, MAC의 측거 관련 부분을 고칩니다. 절 번호는 통합본이 바뀔 때마다 이동하므로, 원문에서는 목차에서 "HRP UWB PHY", "LRP UWB PHY" 같은 **절 이름**으로 찾는 것이 가장 확실합니다. 이 핸드북의 스펙 박스도 절 이름을 기준으로 적습니다.

## 개정판 읽기 { .l2 }

개정판은 **편집 지시문**으로 쓰여 있어서 단독으로는 문맥이 끊깁니다.

| 표기 | 뜻 |
|---|---|
| *Change the following paragraph as follows:* | 기존 문단 수정. 추가는 밑줄, 삭제는 취소선 |
| *Insert the following new subclause:* | 새 하위 절 추가 |
| *Replace …* | 통째로 교체 |

읽는 순서는 이렇게 권합니다.

1. 802.15.4z의 **개요 절과 정의**에서 새 용어(ERDEV, STS, BPRF, HPRF, 측거 라운드 등)를 먼저 익힙니다.
2. **HRP UWB PHY 절의 변경**을 통합본의 같은 절과 나란히 펴 놓고 읽습니다.
3. **MAC의 측거 관련 변경**(측거 IE, 측거 라운드, 측거 방식)을 읽습니다.
4. 마지막으로 정보성 부록에서 측거 계산 예와 보안 고려를 봅니다.

??? expert "전문가 노트 — 무료 열람과 초안 번호"
    IEEE 802 표준은 발행 후 일정 기간(현재 6개월)이 지나면 **IEEE GET Program**에서 무료로 내려받을 수 있습니다. 진행 중인 개정판 초안(예: P802.15.4ab/Dx.y)은 작업 그룹 회원 영역이나 IEEE SA를 통해 구해야 합니다.

    초안 번호 `D2.0`처럼 정수 부분이 바뀌는 시점은 보통 **투표 단계의 전환**(작업 그룹 투표 → SA 투표)을 뜻합니다. 초안 단계의 필드 이름이나 값은 최종본에서 바뀔 수 있으므로, 이 핸드북은 4ab 내용을 "논의 중"으로 표시하고 단정하지 않습니다. 2025년 TG4ab 문서(15-25-0378)는 SA 투표를 2026년 초에 시작하고 2026년 12월에 RevCom 제출을 목표로 잡았습니다. 최종 승인 여부는 IEEE 802.15 TG4ab 페이지에서 확인하세요.
