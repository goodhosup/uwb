# 공통 기초

이 섹션은 UWB의 모든 PHY와 측거 방식이 공통으로 기대는 원리를 다룹니다. PHY·측거 페이지로 넘어가기 전에 여기서 "왜 넓은 대역이 정밀한 시간인가"를 잡아 두면 이후 페이지가 훨씬 쉽게 읽힙니다.

| [대역폭과 시간 분해능](bandwidth-resolution.md) | 500 MHz는 거리로 몇 cm인가? 분해능과 정확도는 어떻게 다른가? |

!!! basic "Wi-Fi·셀룰러와 다른 점 미리 보기"
    1. **OFDM이 아니라 펄스** — 주파수를 잘게 나누지 않고, 시간 축에서 짧은 펄스를 보냅니다.
    2. **세기가 아니라 시각** — 성능의 핵심은 수신 신호 세기보다 "첫 경로가 언제 도착했나"를 얼마나 정확히 아느냐입니다.
    3. **잡음 아래의 신호** — 전력 밀도 한도가 낮아서, 수신기는 수백–수천 개 펄스를 모아(상관) 신호를 끌어올립니다.
