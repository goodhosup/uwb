# 임펄스 라디오와 펄스

!!! spec "규격 · 개정판"
    IEEE 802.15.4-2020 HRP UWB PHY 절 (기준 펄스 모양, 칩 레이트 499.2 MHz, 버스트 구조) · 802.15.4z-2020 (BPRF·HPRF) · FCC 47 CFR 15.503 (UWB 정의)

!!! basic "한눈에 보기"
    보통의 무선은 일정한 주파수의 **반송파**를 계속 내보내면서 그 진폭·위상을 바꿔 정보를 싣습니다. **임펄스 라디오**는 반대로 아주 짧은 **펄스**를 띄엄띄엄 보냅니다.

    - 펄스 하나는 약 **2 ns** — 빛이 60 cm를 가는 시간
    - 시간이 짧은 신호는 주파수 축에서 넓게 퍼집니다(푸리에 변환의 성질). 2 ns 펄스 ≈ **500 MHz** 대역
    - 정보는 펄스의 **극성(+/−)**이나 **위치(언제 보냈나)**에 싣습니다

    북을 "둥" 하고 한 번 치는 것과 같습니다. 짧게 칠수록 낮은 소리부터 높은 소리까지 넓은 주파수가 섞여 나오고, 메아리가 돌아오는 시각을 정확히 잴 수 있습니다.

## 시간이 짧으면 대역이 넓다 { .l2 }

펄스의 길이 \(T\)와 대역폭 \(B\)는 반비례합니다(\(B \approx 1/T\)). UWB 표준은 펄스를 직접 정의하기보다 **기준 펄스와의 상관 조건**으로 모양을 제한하며, 칩 레이트 499.2 MHz에 맞춰 한 칩(약 2.003 ns)에 펄스 하나가 들어가는 구조입니다.

| 채널 폭 | 칩 시간 | 편도 거리 환산 |
|---|---|---|
| 499.2 MHz | 2.003 ns | 0.60 m |
| 1331.2 MHz (Ch4·Ch11) | 약 0.75 ns | 약 0.23 m |

## 펄스에 정보 싣기 { .l2 }

| 방식 | 원리 | 802.15.4 HRP에서 |
|---|---|---|
| BPSK (극성) | 펄스를 +로 보내면 0, −로 보내면 1 | 버스트의 극성으로 1비트 |
| PPM / BPM (위치) | 심볼 구간의 앞쪽/뒤쪽 어디에 펄스를 놓느냐 | 버스트 위치로 1비트 (BPM) |
| OOK (켜고 끄기) | 펄스가 있으면 1, 없으면 0 | LRP 등 저전력 방식 |

HRP UWB는 둘을 합친 **BPM-BPSK**를 씁니다. 심볼 하나를 앞·뒤 반으로 나눠 **버스트 위치로 1비트, 버스트 극성으로 1비트**를 싣습니다. 수신기가 위상(극성)을 모르는 단순한 비동기 수신기여도 위치 비트는 읽을 수 있게 만든 설계입니다. 상세는 [변조와 부호화](../phy/modulation-coding.md)에서 다룹니다.

## 펄스 반복 주파수(PRF) { .l2 }

펄스를 얼마나 자주 보내느냐가 **PRF**입니다. 칩 레이트는 499.2 MHz이지만, 모든 칩에 펄스를 넣지는 않습니다.

| 모드 | 평균 PRF | 특징 |
|---|---|---|
| 802.15.4a 기존 HRP | 약 3.9 / 15.6 / 62.4 MHz | 낮은 PRF → 펄스당 에너지 큼 |
| 802.15.4z **BPRF** | 62.4 MHz | 스마트폰·차량 키의 기본 |
| 802.15.4z **HPRF** | 124.8 / 249.6 MHz | 더 촘촘한 펄스, 높은 데이터율 선택지 |
| LRP | 수 MHz 이하 | 저전력·저복잡도 |

전력 밀도(dBm/MHz) 한도가 정해져 있으므로, PRF가 낮으면 펄스 하나에 더 큰 에너지를 실을 수 있고, PRF가 높으면 펄스당 에너지는 작지만 같은 시간에 더 많은 펄스를 보냅니다. 단, 규제에는 평균 한도 외에 **피크 전력 한도**(FCC: 50 MHz 대역에서 0 dBm)도 있어서 PRF를 마냥 낮출 수는 없습니다. 자세한 비교는 [BPRF와 HPRF](../phy/bprf-hprf.md)에 있습니다.

??? expert "전문가 노트 — 임펄스 라디오 송수신기의 실제"
    **송신기.** 교과서 속 임펄스 라디오는 가우시안 펄스의 미분형을 안테나에 바로 넣는 "반송파 없는" 구조지만, 표준 HRP UWB는 채널 중심 주파수로 업컨버전된 대역 제한 펄스를 씁니다. 그래서 같은 칩이 채널 5와 9를 PLL 설정만 바꿔 오갈 수 있습니다.

    **수신기.** 임펄스 신호는 펄스 사이가 비어 있어 순간 SNR이 낮고, 수신기는 수 GS/s급 샘플링 또는 아날로그 상관 후 샘플링으로 펄스를 모읍니다. 프리앰블 구간에서 코드 상관값을 누적한 결과가 곧 채널 임펄스 응답(CIR) 추정이며, 측거 타임스탬프는 이 CIR의 첫 경로에서 나옵니다([수신기 구조와 첫 경로 검출](../phy/receiver.md)).

    **에너지 검출 수신기.** 802.15.4a가 BPM을 넣은 이유는 극성을 모르고 에너지만 모으는 비동기(non-coherent) 수신기도 허용하기 위해서입니다. 이런 수신기는 저전력이지만 측거 정밀도와 감도에서 동기 수신기보다 불리합니다.
