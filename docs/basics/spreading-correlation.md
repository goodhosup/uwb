# 확산 스펙트럼과 상관

!!! spec "규격 · 개정판"
    IEEE 802.15.4-2020 HRP UWB PHY 절 (SHR: SYNC·SFD, 3진 프리앰블 코드 길이 31·127) · 802.15.4z-2020 (HPRF용 길이 91 코드, STS)

!!! basic "한눈에 보기"
    UWB 신호는 전력 밀도가 매우 낮아서, 펄스 하나만 보면 잡음에 묻혀 있습니다. 수신기는 **약속된 패턴**을 알고 있으므로, 받은 신호와 그 패턴을 겹쳐 보며(**상관**) 일치하는 지점을 찾습니다.

    시끄러운 운동장에서 친구가 늘 쓰는 리듬으로 박수를 치면, 소리가 작아도 그 리듬을 알아듣는 것과 같습니다. 같은 패턴을 **여러 번 반복**하면 신호는 반복 횟수만큼 쌓이고 잡음은 그보다 덜 쌓여서, 잡음 아래의 신호가 위로 올라옵니다.

## 프리앰블과 코드 { .l2 }

HRP UWB 프레임의 맨 앞 **SHR(동기 헤더)**은 같은 코드 심볼을 여러 번 반복한 **SYNC**와, 끝을 알리는 **SFD**로 되어 있습니다.

| 요소 | 내용 |
|---|---|
| 프리앰블 코드 | +1, 0, −1로 된 **3진 코드**. 길이 31 또는 127 (4z HPRF는 길이 91 추가) |
| 확산 | 코드의 각 원소 사이에 0을 끼워 넣어 심볼을 만듦 (PRF 결정) |
| SYNC 반복 수 | 16, 64, 1024, 4096 심볼 등 (4z BPRF는 주로 64 이상) |
| SFD | 짧은 고정 패턴. SYNC가 끝나는 시점을 정확히 알려 줌 |

길이 31 코드는 채널마다 몇 개씩 할당되어 있어서, 같은 채널을 쓰는 이웃 네트워크가 **다른 코드**를 고르면 서로를 덜 방해합니다. 코드 할당표는 [프리앰블 코드](../phy/preamble-codes.md)에서 다룹니다.

## 왜 이 코드인가: 완전 주기 자기상관 { .l2 }

UWB 프리앰블 코드는 **Ipatov 3진 코드**로, 주기적으로 반복할 때 **자기상관의 옆봉우리가 0**이 되는 성질이 있습니다.

| 성질 | 측거에 주는 이점 |
|---|---|
| 정렬된 지점에서만 상관 봉우리 | 잘못된 시각을 첫 경로로 착각하지 않음 |
| 옆봉우리 0 | 상관 결과가 곧 **깨끗한 CIR 추정** |
| 서로 다른 코드 간 상관 낮음 | 코드 분할로 공존 |

수신기가 프리앰블 동안 상관값을 누적하면, 그 결과 배열이 곧 **CIR**입니다. 측거 타임스탬프는 이 CIR에서 첫 경로를 찾아 정합니다([UWB 채널과 다중 경로](channel-multipath.md)).

## 처리 이득 { .l2 }

같은 패턴을 \(N\)번 모으면 신호 에너지는 \(N\)배, 잡음 에너지도 \(N\)배지만 잡음은 무작위로 더해지므로 **SNR이 \(N\)배(10·log₁₀N dB)** 좋아집니다.

| 누적한 코드 심볼 수 (심볼 1개 대비) | 추가 이득 |
|---|---|
| 16개 | 약 12 dB |
| 64개 | 약 18 dB |
| 1024개 | 약 30 dB |

심볼 하나 안에서도 코드의 펄스들을 모으는 이득이 따로 있으므로, 실제 상관 이득은 이 값에 코드 길이만큼의 이득이 더해집니다.

프리앰블을 길게 하면 감도가 좋아져 더 먼 거리에서 동기와 측거가 되지만, 공중 시간과 전력 소모가 늘어납니다. 이 절충이 [링크 버짓](link-budget.md)과 802.15.4ab의 MMS 측거 같은 아이디어로 이어집니다.

??? expert "전문가 노트 — 3진 코드, 비동기 수신기, STS"
    **3진 코드.** Ipatov 코드는 원소에 0이 섞여 있어 완전 주기 자기상관을 이진 코드보다 만들기 쉽습니다. 수신기가 극성을 모르는 에너지 검출 수신기여도 코드의 0/비0 패턴으로 동기를 잡을 수 있습니다.

    **주기 상관의 한계.** 옆봉우리 0은 **주기적** 상관에서만 성립합니다. 프레임 경계나 프리앰블 끝 부분에서는 비주기 성분이 생기므로, 수신기는 SYNC 안쪽에서 CIR을 누적합니다.

    **STS와의 차이.** 프리앰블 코드는 공개·고정이라 누구나 미리 만들 수 있습니다. 따라서 공격자가 프리앰블을 미리 보내 첫 경로를 앞당기는 공격이 가능합니다. 802.15.4z의 **STS**는 세션 키로 만든 의사 난수 시퀀스라 미리 만들 수 없고, STS 상관으로 얻은 CIR을 측거에 쓰면 이런 공격을 막을 수 있습니다. 대신 STS는 주기 자기상관 성질이 없어 상관 결과에 잡음 같은 옆봉우리가 남으므로, 길이를 충분히 길게 하고 첫 경로 판정을 보수적으로 해야 합니다([STS](../phy/sts.md)).
