# 프리앰블 코드

!!! spec "규격 · 개정판"
    IEEE 802.15.4-2020 HRP UWB PHY 절 (SHR 프리앰블: 길이 31·127 3진 코드, 코드 인덱스와 채널 대응, 확산 계수) · 802.15.4z-2020 (HRP-ERDEV: 길이 91 코드, 프리앰블 길이 선택지 확장) · FiRa UCI 파라미터 (프리앰블 코드 인덱스)

!!! basic "한눈에 보기"
    프리앰블은 **정해진 코드 한 토막(심볼)을 계속 반복**한 것입니다. 코드는 +1, −1, 0 세 값으로 된 **3진(ternary) 수열**이고, 0인 자리에서는 펄스를 보내지 않습니다.

    이 코드는 "자기 자신과 겹쳐 볼 때 딱 맞는 위치에서만 큰 값이 나오고, 조금이라도 어긋나면 0이 되는" 특별한 성질을 갖도록 골랐습니다. 그래서 수신기가 코드와 수신 신호를 상관시키면 **반사파마다 깔끔한 봉우리 하나씩**이 생기고, 이것이 곧 채널 임펄스 응답(CIR)입니다.

    코드는 이름표 역할도 합니다. 같은 채널에서 서로 다른 코드를 쓰는 두 네트워크는 상대 신호를 상관해도 큰 봉우리가 생기지 않아 덜 간섭합니다.

## 코드 길이와 인덱스 { .l2 }

| 코드 인덱스 | 코드 길이 | 쓰는 모드 | 프리앰블 평균 PRF |
|---|---|---|---|
| 1–8 | 31 | 레거시 HRP (평균 PRF 약 3.9·15.6 MHz) | 약 16.1 MHz (확산 계수 64면 약 4.03 MHz) |
| 9–24 | 127 | 레거시 HRP 62.4 MHz, **BPRF** | 약 62.89 MHz |
| 25–32 | 91 | **HPRF** (802.15.4z 추가) | 약 111.09 MHz |

각 채널에는 쓸 수 있는 코드가 정해져 있고, 채널마다 최소 두 개 이상의 호환 코드가 있습니다. 길이 127 코드 중 9–12번은 모든 499.2 MHz 채널에서 쓸 수 있어 BPRF 기기의 기본 선택지가 되고, 실제 FiRa·스마트폰 설정에서도 이 범위의 인덱스가 흔히 보입니다. 나머지 일부 코드는 넓은 채널이나 특정 용도로 묶여 있습니다.

길이 91 코드는 0이 적은 "조밀한" 3진 수열이라 같은 시간에 더 많은 펄스(에너지)를 보낼 수 있습니다. 대신 레거시·BPRF 기기와는 호환되지 않고 선택 사항이라, 이를 지원하지 않는 칩도 있습니다.

## 확산 계수와 프리앰블 길이 { .l2 }

코드의 각 원소 사이에는 \(L-1\)개의 빈 칩을 끼워 넣습니다. 이 \(L\)을 **확산 계수**라 합니다. 프리앰블 심볼 하나의 길이는 "코드 길이 × \(L\)" 칩입니다.

| 코드 | \(L\) | 심볼 길이 | 심볼 시간 |
|---|---|---|---|
| 길이 31 | 16 | 496 칩 | 약 993.6 ns |
| 길이 127 | 4 | 508 칩 | 약 1017.6 ns |

이 심볼을 몇 번 반복하느냐가 **프리앰블 길이(PSR, Preamble Symbol Repetitions)**입니다.

| 모드 | 선택 가능한 PSR (SYNC 반복 수) |
|---|---|
| 레거시 HRP · BPRF | 16, 64, 1024, 4096 |
| HPRF | 16, 24, 32, 48, 64, 96, 128, 256 |

프리앰블이 길수록 상관 에너지가 쌓여 먼 거리·약한 신호에서도 검출과 CIR 추정이 좋아지지만, 공중 시간과 전력이 늘어납니다. 근거리 측거가 주 용도인 BPRF 기기는 64심볼이 흔한 기본값입니다([링크 버짓](../basics/link-budget.md)).

??? expert "전문가 노트 — 완전 주기 자기상관과 그 한계"
    HRP 프리앰블 코드는 **완전 주기 자기상관**을 갖는 3진 수열(Ipatov 수열 계열)입니다. 코드 \(c_n\)(길이 \(N\))의 주기 자기상관은

    \[
    R(k) = \sum_{n=0}^{N-1} c_n\, c_{(n+k) \bmod N} =
    \begin{cases} E, & k \equiv 0 \pmod N \\ 0, & \text{그 외} \end{cases}
    \]

    입니다(\(E\)는 0이 아닌 원소 수). 프리앰블은 같은 심볼을 반복하므로 수신기는 주기 상관을 계산할 수 있고, 그 결과는 이론상 **곁가지(sidelobe)가 없는 CIR**입니다. 그래서 약한 첫 경로 바로 옆에 센 반사파가 있어도 곁가지가 첫 경로를 가리지 않습니다.

    한계도 분명합니다.

    - **예측 가능성**: 프리앰블은 공개된 반복 수열이라 공격자가 미리 만들어 보낼 수 있습니다. 이 때문에 보안 측거에서는 프리앰블 CIR만 믿지 않고 [STS](sts.md)를 씁니다.
    - **CIR 창 길이**: 주기 상관은 심볼 시간(약 1 µs, 약 300 m)마다 반복되므로, 그보다 긴 지연은 앞쪽으로 접혀 보입니다. 실내에서는 문제되지 않습니다.
    - **주파수 오프셋**: 송수신 클럭 차이가 있으면 긴 누적 동안 위상이 돌아 상관 이득이 줄어듭니다. 수신기는 프리앰블 구간에서 오프셋을 추정해 보정합니다([수신기 구조와 첫 경로 검출](receiver.md)).
    - **코드 간 간섭**: 서로 다른 코드 사이의 교차상관은 0이 아니라 "작을" 뿐입니다. 가까운 강한 송신기는 다른 코드를 써도 간섭원이 됩니다.

    평균 PRF는 "심볼 안의 0이 아닌 펄스 수 ÷ 심볼 시간"입니다. 길이 31 코드에서 \(L=16\) 대신 \(L=64\)를 쓰면 심볼이 네 배 길어져 평균 PRF가 약 16.1 MHz에서 약 4.03 MHz로 내려갑니다.
